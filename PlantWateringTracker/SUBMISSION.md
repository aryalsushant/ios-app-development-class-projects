# Plant Watering Tracker Submission Notes

## Assignment Requirements

- Includes two working buttons: `Water plant` and `Skip a day`.
- Uses `@State` variables to update the UI when either button is tapped.
- Updates the plant emoji, title, message, progress bar, water count, and skipped-days count.
- Keeps the interface clean and easy to read.
